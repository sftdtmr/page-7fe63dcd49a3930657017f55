使用场景

远程办公与资料检索

当文档、代码托管或内部面板对网络路径敏感时，用客户端做分流比全局代理更可控。先保证办公域名走加速，再把国内常用服务留在直连，减少证书报错和登录异常。

流媒体与内容平台

观看或检索海外内容时，重点不在“宣称解锁了什么”，而在客户端是否支持按域名分流、是否便于切换线路。遇到缓冲，优先换规则或节点组，而不是反复重装软件。

学习、开发与测试

拉取依赖、阅读文献、对照海外文档时，稳定的 TCP 路径往往比花哨界面重要。桌面客户端方便保存多份配置，也方便你把终端流量与浏览器流量分开处理。

什么时候不必强行上加速器

仅访问国内站点、对延迟不敏感、或设备无法安装任何代理客户端时，硬上梯子只会增加故障面。快柠檬更适合已经明确需要跨境路径、并愿意花几分钟完成订阅导入的人。

公共 Wi‑Fi 下，客户端加密链路可以降低明文嗅探风险，但仍需配合站点自身的 HTTPS 与账号安全习惯。

客户端选择（本页重点）

快柠檬的使用体验几乎完全取决于客户端。同一份机场订阅，在不同软件里的分流精度、耗电和更新方式并不相同。下面按端给出选择原则，具体安装包请到下载模块获取，正文不另附地址。

Windows / macOS适合长时间在线、需要规则分流和系统代理的人。优先选能导入通用订阅、能看日志、能切换全局/规则模式的桌面客户端。笔记本电池场景可关闭 UDP 或降低并发，避免无意义耗电。
Android关注后台保活、订阅自动更新和分应用代理。系统省电策略可能切断隧道，需要在系统设置里给客户端足够的自启动权限，而不是怀疑订阅失效。
iOS / iPadOS商店政策使客户端来源更受限。先确认你已有可用的商店客户端或配置描述文件，再导入快柠檬订阅。不要在不明来源的安装包里寻找“破解加速器”。

挑选时只问三个问题

一，系统是否被该客户端正式支持；二，它能否直接粘贴订阅链接而不是手搓单个节点；三，你是否需要分应用/分域名，而不是全局一把梭。

不建议的做法

同一台设备叠装多个内核却同时开启系统代理；把订阅二维码发到公共群；用过期的第三方配置覆盖快柠檬订阅。这些都会让“连不上”变得无法定位。

路由器或软路由适合全家共享，但要求你会维护订阅更新与 DNS。若只有一台主力电脑，先从桌面客户端开始。

操作说明

确认设备与客户端匹配

打开本页「客户端选择」，按系统选定一款能导入订阅的软件。只保留一个系统代理开关，避免多个加速器抢占端口。

完成快柠檬订阅

进入套餐模块下单。到账后在用户中心复制订阅链接，不要把链接写进备忘录截图长期流传。

导入并更新一次

在客户端选择“从 URL 导入”或等价入口，粘贴链接后手动更新。看到策略组或节点列表出现，才说明订阅生效。

先规则后全局

日常使用优先规则模式：跨境域名走代理，国内直连。只有在需要整机出境时才开全局，减少登录态丢失。

连通性自检

打开目标站点、看客户端日志是否握手成功。失败时按「订阅能否更新 → DNS 是否异常 → 是否被系统省电杀死」的顺序排查，而不是连续切换十余个节点。

常见问题

快柠檬是什么？和普通加速器有何不同？

快柠檬是以机场订阅为核心的网络加速服务，也就是把可用线路放进你自己的 VPN / 梯子客户端里使用。它强调可更新的订阅，而不是单一应用内写死的线路列表。你需要自行完成客户端选择与导入。

怎样选择客户端才不容易出错？

先锁系统，再锁能力：必须支持订阅 URL、能看连接日志、能在规则与全局之间切换。桌面端适合分流调试，移动端适合出门，路由器适合共享。不要为了“界面好看”换掉唯一能更新订阅的软件。

导入订阅后显示节点但打不开网页怎么办？

依次检查：系统代理是否被其他软件占用、是否处于规则模式却没有匹配到目标域名、本地 DNS 是否污染、客户端是否被省电策略挂起。能更新订阅说明账号通常有效，问题多半在本地网络栈而不是“套餐消失”。

可以同时在多台设备使用吗？

可以，但应把同一订阅放进你信任的设备，并在客户端里避免无意义的重复连接。具体可同时在线的数量以套餐模块说明为准。公共电脑上使用完毕应删除本地配置。

快柠檬官网提供官方下载吗？第三方站点能用吗？

客户端请只通过本页下载模块获取。正文不提供额外地址，也不维护第三方镜像。来路不明的“破解版加速器”会替换你的订阅、窃取账号或植入广告，这与网络加速目标相反。

流量用完或线路变慢时该怎么处理？

先在客户端更新订阅，排除本地缓存过期；再切换规则组而不是盲目重装。若确认用量耗尽，回到套餐模块按自己的节奏续订或调整方案。不要在社交群里交换他人的快柠檬订阅链接。
